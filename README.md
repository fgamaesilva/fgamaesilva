## O que eu construo

- **Plataformas de inteligência de aquisição**: painéis que juntam investimento em mídia, cadastros e conversões numa fonte única, em que a mesma métrica dá o mesmo número em todas as telas.
- **Pipelines de dados de marketing**: Google Ads, Meta Ads, TikTok Ads e GA4 para BigQuery e PostgreSQL, com checagens diárias de reconciliação.
- **Conversões server-side**: Meta Conversions API e Google Ads Data Manager API.
- **Servidores MCP e agentes de IA**: assistentes de IA com acesso aos dados e à operação de mídia, em que toda mudança passa por aprovação humana.

## Como eu trabalho

- Desenvolvimento assistido por IA (Claude Code e Codex): eu defino a arquitetura, as regras de negócio e a validação, e os agentes escrevem a maior parte do código.
- Decisão de escala se apoia em dado maduro, não no resultado do dia.
- IA serve para acelerar quem decide, não para decidir sozinha.
